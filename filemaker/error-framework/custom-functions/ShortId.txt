ShortId ( lengthId ) =
/*
Purpose: Generate a short, human-readable random ID (e.g. for errorID) that a user can easily read out
loud, type, or photograph.

Parameters:
lengthId: desired ID length as a number. Optional; if empty or below 1, defaults to 6.

Returns: text string of lengthId characters, drawn from the 32-character alphabet
"23456789ABCDEFGHJKLMNPQRSTUVWXYZ" (digits 2-9 and A-Z without 0/O and 1/I, to avoid characters that
are easily confused when read aloud or typed).

Collision risk by length:

  Length | Combinations         | 100 IDs         | 1,000 IDs       | 10,000 IDs
  -------|----------------------|-----------------|-----------------|----------------
  4      | 1,048,576            | 1 in 210        | 1 in 2.6        | ~certain
  5      | 33,554,432           | 1 in 6,700      | 1 in 67         | 1 in 1.3 (77%)
  6      | 1,073,741,824        | 1 in 214,700    | 1 in 2,150      | 1 in 22
  7      | 34,359,738,368       | 1 in 6,900,000  | 1 in 68,700     | 1 in 687
  8      | 1,099,511,627,776    | 1 in 220,000,000| 1 in 2,200,000  | 1 in 22,000

Default length 6 is a safe margin for up to ~1,000 IDs/day.

Author: Bas van Genabeek
Version: 1.0.2
Updated: 2026-09-11
Remarks: none
Changelog:
- 1.0.2 (2026-09-11): Added internal ~lengthId mirror of the lengthId parameter for consistency with the
project convention (~ is reserved for internal variables, never used on parameters themselves).
- 1.0.1 (2026-09-11): Renamed CF to ShortId (PascalCase) and parameter to lengthId because length is a FileMaker-reserved word and cannot be used as a parameter name.
- 1.0.0 (2026-09-11): Initial version.
*/
Let (
[
  ~lengthId = lengthId ;

  ~defaultLength = 6 ;
  ~chars = "23456789ABCDEFGHJKLMNPQRSTUVWXYZ" ;
  ~charCount = Length ( ~chars ) ;
  ~effectiveLength = Case ( IsEmpty ( ~lengthId ) or GetAsNumber ( ~lengthId ) < 1 ; ~defaultLength ; GetAsNumber ( ~lengthId ) )
] ;
  Substitute (
    While (
      [ ~i = 0 ; ~result = "" ] ;
      ~i < ~effectiveLength ;
      [ ~i = ~i + 1 ;
        ~result = ~result & Middle ( ~chars ; Ceiling ( Random * ~charCount ) ; 1 ) ]
    ) ;
    "¶" ; ""
  )
)
